Écoute en contexte

Les mots s’enchaînent.

Écrivez une expression, puis ajoutez votre enregistrement. Les cartes sans audio restent dans l’éditeur et sont ignorées pendant l’exercice.

Le brouillon reste dans ce navigateur. Publier écrit data/flow-deck.js dans votre dossier local. Ensuite, publiez vos changements avec GitHub Desktop.

Cartes

Modifier la carte

Les majuscules, la ponctuation et les contractions usuelles sont gérées automatiquement. Ajoutez ici les variantes particulières (par exemple « I dunno »).

Enregistrez à un rythme naturel. L’audio lent est facultatif. Le micro nécessite localhost ou HTTPS ; vous pouvez toujours importer un fichier audio.

Tester la tolérance des réponses

Teste la carte affichée, y compris vos modifications avant enregistrement. La tolérance reste prudente : ajoutez les variantes légitimes dans « Autres réponses acceptées ».

Les enregistrements sont inclus dans le fichier de cartes : aucun service externe nécessaire. Gardez une copie téléchargée après vos modifications.
